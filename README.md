# OGLOG

### Make your git log great again

-----------------------------------

This utility helps you to make your own git log alias

![alt text](https://github.com/m34t0/oglog/blob/master/og-loc.jpg?raw=true)



## Installation

Just run this command in your zsh or bash terminal, mate
```
eval "$(curl "https://raw.githubusercontent.com/m34t0/oglog/refs/heads/master/install.sh")" && oglog_install
```
